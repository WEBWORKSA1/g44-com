Where to start

If you are not sure what kind of headache you have, start with the type finder. If something about this headache feels different or frightening, use the warning-sign checker first. If you get headaches often, the diary is the single most useful thing you can do: two months of entries usually reveal the pattern, the triggers and whether you are near the medication-overuse line.
